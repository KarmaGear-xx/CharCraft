# CharCraft 桌面版 · 需求与实现方案(Electron)

> 版本:v1(桌面版 MVP 基线)/ 状态:待「正式开始编程」
> 本文为开发前基准,不含代码。本版**完全重写、不复用旧代码**。

---

## 1. 项目概述

开发类 [Ginger](https://github.com/DominaeDev/ginger) 的 **SillyTavern 角色卡开发/编辑工具**,以 **Windows 便携版单文件 `.exe`** 交付。

- **框架**:Electron(单一 TypeScript 语言、打包链路最成熟、维护成本最低)。
- **交付形态**:便携版单文件 `.exe`,免安装、双击即用。
- **代码策略**:完全推倒重写,专为桌面设计,不复用网页版代码。
- **功能定位(M1)**:导入 / 生成 / 编辑角色卡,绑定世界书,导出 `.json` / `.png`。

## 3. 硬性约束(不可违反)

1. **语言分层**:UI 中英双语可切换,但仅影响显示层;角色卡数据字段名与内容**恒为英文**。
2. **密钥本地化**:API Key 仅存本机应用数据目录,绝不外传,只发送给用户选择的服务商。
3. **财产保护**:每次启动应用后的**第一次 AI 生成**前弹费用提醒。
4. **内容保护(最高优先级)**:整卡生成前若已有内容,弹覆盖策略 —— 取消 / 清空并覆盖 / 仅填空字段 / 手动选择覆盖目标。

## 4. 功能需求(M1)

### 4.1 导入
- 原生「打开文件」对话框,选择 `.png` / `.json`(`.charx` 归 M2)。
- 解析 `chara_card_v2`(PNG `tEXt`→`chara`)与 `chara_card_v3`(`tEXt`→`ccv3`),对旧 CAI/TavernAI 与缺字段容错。

### 4.2 可视化表单编辑
- **「信息键入」区块**分两组:
  - 核心区:name / description / personality / scenario / first_mes / mes_example / alternate_greetings / system_prompt / creator_notes / tags / creator。
  - 高级选项折叠区:post_history_instructions / character_version / group_only_greetings / avatar。
- 每个字段旁 = **启用/禁用勾选框** + **AI 改写按钮**。
  - 启用 = 写入导出卡片;禁用 = 不写入导出但草稿保留、可恢复;`name` 锁定启用。
- 区块顶部 = 「一句话设定」输入区 + 「开始生成」按钮。

### 4.3 AI 辅助生成
- 模型设置:接口地址 + API Key + 模型名,内置 OpenRouter / DeepSeek 预设,支持自定义 OpenAI 兼容地址。
- 整卡起草、逐字段生成/改写、世界书条目生成。
- 覆盖保护(见 §3.4)、费用提醒(见 §3.3)、输出强制英文。

### 4.4 世界书
- 手动 / AI 生成条目,绑定到 `data.character_book`,随卡导出。
- 条目核心:keys[] / content / enabled / comment / insertion_order;高级折叠:name / description / scan_depth / token_budget / recursive_scanning / case_sensitive / selective / constant / position / priority / use_regex / secondary_keys[]。

### 4.5 导出
- 原生「另存为」对话框导出 `.json` 与 `.png`(写回 `tEXt` 的 chara/ccv3 块)。

### 4.6 其他
- 中英双语切换;本地草稿自动保存(崩溃可恢复)。

## 5. 桌面版架构(Electron 三层)

### 5.1 main(主进程,Node.js)
- 窗口管理、原生对话框、文件读写、AI 直连、配置存取、应用生命周期。

### 5.2 preload(预加载)
- 用 `contextBridge` 暴露安全 API:`openCard` / `saveJson` / `savePng` / `aiChat` / `getConfig` / `setConfig`。
- 渲染进程不直接接触 Node/文件系统,全部走 IPC。

### 5.3 renderer(渲染进程,React + TS)
- 界面与状态;核心逻辑(PNG 编解码、卡片解析/序列化、AI 客户端、字段模型)在渲染进程实现。

### 5.4 数据存储
- 草稿自动保存 → 应用数据目录 `draft.json`。
- 设置 → 应用数据目录 `config.json`(语言、AI 配置)。

### 5.5 AI 调用
- 由**主进程**直连 OpenAI 兼容接口,**无浏览器 CORS 限制**,DeepSeek 直连也可用。

## 8. 验收标准(M1)

1. `.exe` 双击可运行,无白屏、无闪退。
2. 原生对话框导入 `demo/` 7 张卡 → 编辑 → 导出 `.png`/`.json` → 再导入,数据一致(往返)。
3. AI 直连(OpenRouter / DeepSeek)整卡 + 逐字段 + 世界书生成可用;费用提醒与覆盖保护生效。
4. 中英双语切换不影响卡片数据(恒英文)。
